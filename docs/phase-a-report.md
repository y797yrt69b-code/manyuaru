## できること

- 本人写真と複数の服を入力、カテゴリ・内側→外側の順序確認。同意なし/無断省略は拒否。
- MockProviderとfal実Provider候補を交換。モックは元写真を返すだけで常時デモ表示、実APIは承認・料金・鍵・円上限・件数・同意版が揃うまで拒否。
- PostgreSQL永続キューと専用worker、受付202+polling、冪等受付、リース・送信後結果不明の自動再送防止。
- 品質評価、時間、最大見積/実費未確定の区別、履歴、CSV、モック除外の補助集計。
- 実API受付の同時予算/件数制御、削除でも費用記録を保持。画像実体/EXIF/容量/画素数の確認。
- privateローカル画像、owner RLS、同一Originとloopback制限、入力/履歴/結果の削除、後着結果破棄、削除ファイルの永続再試行。
- 日本語README、architecture/api/AI評価/privacy/cost/validation/operations、秘密値なし.env.example、Phase A migration 001/002、60ケースの計画CSV。
