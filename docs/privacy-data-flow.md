# 写真の流れと削除

## ローカルモック

ブラウザで本人/服を選択 → loopback API → 形式/容量/画素数/デコード確認 → sharp再エンコード・EXIF除去 → `.poc-data/<ownerUUID>/<assetUUID>.jpg`（ディレクトリ700/ファイル600） → 非公開DBのパス・寸法 → worker → モックは同じ本人写真を新しい結果として保存 → 所有者確認済みの画像APIで表示。

写真、顔、氏名、メール、鍵、外部署名URLをログ/CSV/イベント属性に入れない。Phase Aには解析SDK/外部フォント/広告SDKはない。Next.js telemetryは手順で無効にする。コメントには個人情報を入力しない。sessionStorageは同一タブの入力UUID/服カテゴリ/元ファイル名のみで、鍵や画像本体は入れない。ファイル名に個人名を使わないでください。

所有者はサーバー固定の運営者UUID。DB RLSは他所有者UUIDを拒否するが、画面のログイン機能はない。同じ端末を複数参加者へ渡す運用/ネットワーク公開は禁止。Phase Bの認証・招待・認可を作ってから別利用者の画像を扱う。

## 実API候補（未実行）

本人/服の再エンコードJPEGと重ね順指示文をサーバー → `queue.fal.run` → falおよびモデル供給者（FASHN/Google）へ送る。入力はdata URIでSDKのpublic uploadは不使用。falのキューは外部に永続し、実行IDだけをローカルDBへ保存する。返る画像はdata URI優先、fal CDN v3bの場合は短期トークンで読み出す。外部URLは恒久保存しない。

公式の通常CDN URLはリンクを知る人が閲覧できる。今回はStore-IO=0、出力1時間保持+default forbid、sync_mode=data URIを要求する。**実効性をまだ確認していない**。fal ACLはv3 CDN限定、外部FASHN CDNへ適用しない。第三者CDN出力は取得拒否し、課金不明の予約を維持する。拒否できても外部で画像が生成・保存された事実は消せない。下流事業者の保持/学習/削除/地域/再委託を調べ、具体的な説明と同意版が準備されるまで実送信しない。

`LIVE_TERMS_REVIEWED` は事実確認の記録ができたときだけtrue。写真を「学習に使わない」「即時完全削除」と保証する表現は使わない。送信先を変える場合は同意文版・再同意・Provider設定を更新し、旧版では受付拒否する。

## 保存期限

Phase Aは全入力/結果を90日で削除対象にする（登録衣服を無期限保持するMVPとは異なる）。workerが毎分掃除し、期限を超えた画像はAPIで表示しない。workerを止めると物理削除は止まるので、運営者は日次で起動状態を確認する。DBのジョブは90日経過で入力/評価を消し非表示にする。費用台帳は再送/予算照合のため写真とは分離して保持する。

個別削除：即非表示 → 入力/プロンプト/評価/結果メタデータを消す → 他ジョブと共有していない画像をunlink。queuedは取消、runningは外部照合/取消依頼。後着した結果は保存しない。外部取消は処理停止や無課金、外部写真削除を保証しない。写真利用・送信同意の個別署名証跡を集める運用は運営者の仕事。

全削除：停止した状態で `DELETE_ALL_POC=YES npm run purge`。ローカル画像・評価・未使用画像・ローカルbackupを消す。金額/外部ID/状態/承認の最小台帳は残す。画像IDが消えたタブは閉じるか入力クリアする。DBコミットとファイル操作は単一トランザクションにできないため、削除パスを `deletion_files` に永続化し、ワーカーが毎分再試行する。削除失敗時は保存領域確認が必要。管理するPC/バックアップの権限は別途保護する。

## バックアップ・クラウドの限界

手動backupはDB+画像を含む。自動期限削除/暗号化は未実装。削除依頼があればbackupも削除する。クラウド環境の公開snapshotやユーザーがコピーした画像はこのコマンドでは消せない。保存/削除周期は採用サービスと契約確認が必要で日数は未確定。Supabase/Vercelをまだ契約していないためバックアップ消去日数を架空に設定しない。実API削除確認も未完了。

非公開Supabase bucket/RLS定義はmigrationに用意したが、Supabase Storageの実体認可・署名URL・他人参照拒否の検証はMVP前に必要。現在のlocal filesystem試験をSupabase Storage試験として報告しない。
